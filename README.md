# AI Lecture Notes Assistant — Frontend

A web app that turns lecture recordings into structured, searchable study material: automatic transcription, AI-generated notes (key concepts, definitions, formulas, emphasized points), and a course-level Q&A chat with citations.

The Next.js application lives in [`lecture-notes-frontend/`](lecture-notes-frontend) — see [its README](lecture-notes-frontend/README.md) for features, setup, environment variables, and deployment notes.

Backend API: [AI Lecture Notes Backend](https://github.com/Zee-Gg/AI-Lecture-Notes-Backend)
